# Healthcare Analytics Power BI Dashboard

## Project Overview
The Healthcare Analytics Dashboard is an interactive Power BI project designed to analyze hospital operations, patient records, and financial performance. It transforms raw healthcare data into meaningful visual insights, enabling hospitals and healthcare professionals to make informed, data-driven decisions.The dashboard provides a comprehensive overview of patient demographics, medical conditions, billing trends, insurance providers, and hospital performance in a single interactive report.

## Objectives
* Analyze patient demographics and healthcare trends.
* Monitor hospital admissions throughout the year.
* Evaluate billing amounts across different medical conditions.
* ompare insurance provider contributions.
* Build an interactive dashboard for healthcare decision-making.

## Dataset

The dataset includes healthcare-related information such as:

- Patient Name
- Gender
- Age
- Blood Type
- Medical Condition
- Doctor
- Hospital
- Admission Type
- Test Result
- Insurance Provider
- Billing Amount
- Admission Date

## Dashboard Features
* Displays key healthcare KPIs, including Total Patients, Average Age, Total Billing Amount, Total Hospitals, and Total Rooms.
* Analyzes patient distribution by gender, medical conditions, and monthly admission trends.
* Provides insights into billing amounts by medical condition and monthly billing performance.
* Visualizes insurance provider-wise billing distribution for financial analysis.
* Includes interactive filters for detailed analysis by gender, age group, doctor, hospital, insurance provider, medical    condition, and admission type.
